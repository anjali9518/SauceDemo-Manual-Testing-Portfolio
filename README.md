# SauceDemo – Manual QA Testing Portfolio

## Project Overview
This is a personal Manual QA Testing project performed on the SauceDemo demo website.

The objective was to test website functionality, identify potential issues, and document test cases and results.

## Application Under Test
https://www.saucedemo.com/

## Testing Scope
- Login and Logout
- Product Listing and Sorting
- Product Details
- Shopping Cart
- Checkout Process
- Negative and Boundary Testing

## Tools Used
- Manual Testing
- Microsoft Excel
- Web Browser
- GitHub

## Project Documents
1. Manual QA Test Cases – Test scenarios, test steps, and execution results.
2. Bug Reports – Documented issues with reproduction steps and expected vs actual results.
3. Test Summary Report – Overview of the testing activity and results.

## Project Type
Personal QA Portfolio Project

## Disclaimer
SauceDemo is a publicly available demo application.
This project was conducted for learning and portfolio purposes.
